# Phase 4: review, progress and polish

Back to [PLAN.md](PLAN.md)

## Goal

Both users can see what they have learned, revisit it outside a conversation, and the app is pleasant to use daily.

This phase is deliberately loose. Reprioritise it using what phases 1 to 3 teach us.

## Tasks

### Progress

- [ ] Topic strength view for the Mandarin learner
- [ ] Word list with state, filterable by topic
- [ ] Manual override: mark a word as known or not known
- [ ] Session history with transcripts

### Review

- [ ] Quick review of weak words (see, hear, recall) without starting a conversation
- [ ] Replay audio for a single word or line
- [ ] Saved feedback cards for the English learner

### Tutor quality

- [ ] Tune how fast new words and topics are introduced, based on real usage
- [ ] Slower speech option for Mandarin
- [ ] Custom topics and scenarios

### Polish

- [ ] Home screen: continue, pick a topic, or review
- [ ] Faster first load (lazy load dictionaries)
- [ ] Better handling of poor signal
- [ ] Export your data

### Decide

- [ ] Review free tier experience and decide on paid
- [ ] If paid: budget alert in Google Cloud

## Done when

- Each user can answer "what do I know and what should I practise next" from the app.
